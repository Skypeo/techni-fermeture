## Structure type d'une page produit
La plupart des pages produit (fenêtres, volets, portes, portails, garage, industriel, motorisation, dépannage, stores) suivent le même schéma :
1. **Hero** : grand titre + sous-titre
2. **Section 1** : présentation générale du produit/service
3. **Section 2** : focus matériau / modèle A
4. **Bloc 4 atouts** : 4 mots-clés
5. **Section 3** : focus matériau / modèle B (ou motorisation)
6. **CTA final** : titre incitatif + bouton de conversion

> 💡 Ce schéma récurrent est utile pour créer un **template de page produit** réutilisable dans le nouveau site.
